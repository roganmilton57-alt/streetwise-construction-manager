# Streetwise Construction Manager v2 — Installable PWA

## PC
1. Extract the ZIP.
2. From the folder run:
   `python3 -m http.server 8080`
3. Open `http://localhost:8080`.
4. In Chrome/Edge, use the Install App icon/menu option.

## Android
The app must be served from HTTPS for normal installation.
Open the hosted app in Chrome → browser menu → **Install app / Add to Home screen**.

## Included
- Polished responsive Android/PC UI
- PWA manifest
- Offline service worker
- Install prompt when supported
- Dashboard and 10 construction control modules
- Demo construction data
- Local persistence
- JSON export
- Responsive mobile bottom navigation
